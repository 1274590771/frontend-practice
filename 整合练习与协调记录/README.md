# 城市气象数据整合中心

软件开发综合实践 · 期末大作业原型。把课堂作业五的筛选交互、作业六的数据看板、
作业七的三维场景整合成一个入口下的完整页面，主题统一为城市气象数据。

## 运行说明

页面用 `fetch` 读 `data/weather.json`，直接双击打开 `index.html`（`file://` 协议）
会被浏览器的同源策略拦掉，必须在本地起一个静态服务：

```bash
cd 整合练习与协调记录
python -m http.server 8900 --bind 127.0.0.1
```

然后访问 <http://127.0.0.1:8900/index.html>。
用 `python -m http.server` 即可，不需要 Node、也不需要任何后端。

进入三维页有两种方式：点导航栏的「三维地球」直接进入；
或在首页选好城市与时段后点「在三维地球上查看 →」，三维页会按 URL 参数定位到那座城市。

### 演示开关

在地址后加 `?demo=` 可以复现几种异常状态，用于自查和演示：

| 参数 | 效果 |
| --- | --- |
| `?demo=empty` | 模拟服务端返回空数据集，页面显示「暂无数据」 |
| `?demo=error` | 模拟服务端 500，页面显示「加载失败：HTTP 500」 |
| `?demo=slow` | 延迟 3 秒返回，用于观察「加载中」状态 |

三维页同样支持这几个参数。断网场景用浏览器开发者工具切到 Offline，
或临时改掉 `data/weather.json` 的文件名后刷新。

## 目录结构

```
整合练习与协调记录/
├── index.html              入口页：导航 + 首页概览 + 城市查询 + 数据看板
├── css/style.css           自定义样式（Bootstrap 之后引入以保证可覆盖）
├── js/
│   ├── data.js             共享数据层：时段定义、聚合口径、数据加载
│   ├── app.js              状态与交互：加载四态、概览卡片、城市/时段筛选
│   ├── charts.js           可视化：ECharts 柱状图 + Chart.js 折线图
│   └── globe.js            三维地球：经纬度标记、降水柱高、气温配色
├── data/weather.json       统一数据源（4 城市 × 12 月的降水与气温 + 经纬度）
├── three-d/globe.html      三维导览页
├── libs/                   本地依赖库，离线可打开
└── docs/self-check/        质量清单自查证据
```

## 模块构成

| 模块 | 落在哪里 | 说明 |
| --- | --- | --- |
| 页面 | `index.html`、`three-d/globe.html` | 统一入口与四个导航入口，两页可互相往返 |
| 样式 | `css/style.css` | Bootstrap 之上的自定义样式，含窄屏与深色三维页适配 |
| 交互 | `js/app.js` | 城市按钮组 + 时段下拉，改任一项立即重渲染 |
| 数据 | `data/weather.json`、`js/data.js` | 一份数据源 + 一份聚合口径，页面不各自取数 |
| 可视化 | `js/charts.js` | ECharts 柱状图（降水）+ Chart.js 折线图（气温） |
| 三维（进阶） | `js/globe.js`、`three-d/globe.html` | 经纬度定位的城市气象地球仪 |

模块之间不是各画各的：`app.js` 持有唯一的 `state`（城市 + 时段），
图表和三维页都从这一份状态取数，`data.js` 保证两个页面的求和口径一致。
具体表现是首页选「广州 + 上半年」时，概览卡片、明细卡片、柱状图三处
都会得到 865 mm / 21.7 ℃，三维页从同一个链接进去也是同一组数字。

## 资源来源说明

### 数据

- `data/weather.json`：**自建数据集**，依据公开气象年值整理，仅用于课堂演示，
  不是真实气象站观测数据。降水与气温序列沿用了本仓库 `my-dashboard`
  课堂作业六的数据集，本次为其补充了每座城市的经纬度（用于三维地球定位）。

### 第三方库

全部下载到本地 `libs/` 目录，页面不引用任何 CDN，断网也能打开。

| 库 | 版本 | 用途 | 来源 |
| --- | --- | --- | --- |
| Bootstrap | 5.3.3 | 栅格、导航、卡片、表单、按钮 | <https://getbootstrap.com> |
| Apache ECharts | 5.6.0 | 月降水量柱状图 | <https://echarts.apache.org> |
| Chart.js | 4.4.4 | 月平均气温折线图 | <https://www.chartjs.org> |
| three.js | r128 | 三维地球与城市标记 | <https://threejs.org> |
| OrbitControls | 随 three.js r128 | 三维场景的旋转/缩放/平移 | three.js 官方 examples |

### 代码来源

- 筛选交互（改条件后整体重渲染）来自课堂作业五的筛选模式。
- 数据加载的四态处理（加载中／空数据／HTTP 非 2xx／网络异常）与两种图表的骨架
  来自课堂作业六的数据看板。
- 三维场景的搭建方式、`requestAnimationFrame` 动画循环、
  canvas 贴图做文字标签、以及 r128 色彩空间用 `convertSRGBToLinear` 处理的做法，
  来自课堂作业七及本仓库 `my-scene（Three.js版）`。
- 未引入课堂之外的框架，也没有使用后端服务。
